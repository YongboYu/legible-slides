# Theme logos

A theme's `meta.logo` is a path relative to this `themes/` directory.

`kuleuven.json` points at `logos/kuleuven-liris.png`. **That file is not committed here.** The KU
Leuven and LIRIS marks are the university's brand assets; this project is not an official KU Leuven
product and does not redistribute them. Drop your own copy in at that path — the theme is otherwise
complete without it, and the validator never reads it.

`neutral.json` ships no logo at all, which is what brand-free means: omit `meta.logo` entirely.
